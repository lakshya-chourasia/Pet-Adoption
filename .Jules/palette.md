## 2024-03-09 - Fix card overlay and button accessibility
**Learning:** The CSS property `will-change: transform` creates a containing block for absolutely positioned descendants. In a card layout where a link (`a`) uses an `::after` pseudo-element with `position: absolute; inset: 0;` to make the whole card clickable, having `will-change: transform` on the link restricts the pseudo-element to the link's dimensions rather than the card's dimensions. Additionally, icon-only buttons require dynamic `aria-label` and `title` attributes (e.g., "Favorite [Pet Name]") to be accessible to screen readers and provide usable tooltips.
**Action:** Remove `will-change: transform` from `.card-header a` to allow the pseudo-element to size correctly relative to the `.card`. Add context-aware `aria-label` and `title` attributes to all `.icon-button` elements based on the associated pet's name.
