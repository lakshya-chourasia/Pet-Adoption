## 2024-05-23 - Full-Card Link Overlay vs Interactive Children
**Learning:** When using an absolute pseudo-element (`::after`) on a link to create a "full-card link", be careful with `will-change: transform` on the link element. It creates a containing block that constrains the overlay to the link itself, breaking the full-card effect. Also, interactive children (like buttons) inside the card need `position: relative` (or other non-static position) and a higher `z-index` to sit above the overlay and remain clickable.
**Action:** Always verify `z-index` stacking when using full-card link overlays. Use `position: relative` on interactive children to ensure they are accessible. Avoid unnecessary `will-change: transform` on the anchor tag if it's not the element being animated.
