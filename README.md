# Pet Adoption

A simple, responsive web page for a Pet Adoption service. This project showcases available pets for adoption with a clean and modern user interface.

## Features

- **Responsive Design**: Looks great on desktop and mobile devices.
- **Modern UI**: Uses CSS variables, flexbox, and hover effects.
- **Clean Structure**: Semantic HTML5 and separate CSS file.

## Getting Started

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open `app.html` in your web browser.

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Lato, Montserrat, Lexend)
