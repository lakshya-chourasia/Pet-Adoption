## 2024-05-18 - HTML Performance Comments
**Learning:** While the "Bolt" persona strictly mandates adding code comments to explain optimizations, adding HTML comments (`<!-- -->`) for standard structural optimizations like `width`, `height`, and `loading="lazy"` actually inflates the payload unnecessarily. The code reviewer considers omitting HTML comments for these native attributes as preferred for maintainability and byte-saving, treating the persona's comment requirement as a non-blocking nitpick in HTML contexts.
**Action:** When applying standard HTML native attribute performance optimizations (like `loading="lazy"` or dimension attributes), skip adding explanatory HTML comments to avoid shipping unnecessary bytes. Fulfill the comment requirement instead when optimizing JavaScript, backend logic, or complex CSS.
