## 2024-07-12 - Ensure Proper Indentation and Trailing Newlines for Image Lazy Loading Replacements
**Learning:** When writing modification scripts to inject attributes (like `loading="lazy"`) and comments into HTML elements that might span across or be positioned with specific indentation, using a generic `str.replace` without accounting for the actual exact leading whitespace (and avoiding the assumption of a set number of spaces) will lead to failure. Similarly, ensuring trailing newlines matches the document style (`\r\n` for CRLF) is vital so formatting is not broken.
**Action:** When creating execution plans that explicitly replace strings with `str.replace()`, actively verify the exact target strings *including their precise leading whitespace* (e.g., using `re.findall` in a python exploration script) rather than assuming a standard indentation level. Use those exact verified strings as the targets in the plan to guarantee success and satisfy the Groundedness Rule.
