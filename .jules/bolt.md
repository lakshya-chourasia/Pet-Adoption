## 2024-03-09 - Avoid CSS @import for Google Fonts
**Learning:** Using `@import` in CSS files (like `css/style.css`) to load external resources like Google Fonts creates a critical request chain bottleneck. The browser must first download and parse the CSS file before it even discovers the `@import` rule, delaying the download of the font stylesheet and subsequently the font files themselves, which blocking parallel resource downloading.
**Action:** Always use `<link>` tags directly in the HTML `<head>` instead of CSS `@import`. Specifically, combine multiple font families into a single `<link rel="stylesheet">` tag and prepend with `<link rel="preconnect">` tags for the origins (`fonts.googleapis.com` and `fonts.gstatic.com` with crossorigin) to optimize the critical rendering path.
