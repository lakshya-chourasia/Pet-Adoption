## 2026-04-06 - Explicit Dimensions for External Images\n**Learning:** The static Pet Adoption site relied on `placedog.net` URLs that encoded dimensions (e.g., `/300/225`), but the HTML lacked explicit `width` and `height` attributes, which would cause significant Cumulative Layout Shift (CLS) on load. Furthermore, images below the fold were eagerly loaded, wasting bandwidth.\n**Action:** When working with image placeholders or external image services, always parse explicit dimensions from the URL (if available) and add them directly to the HTML attributes. Additionally, always apply `loading="lazy"` to offscreen content to improve Largest Contentful Paint (LCP).
