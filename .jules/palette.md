## 2024-05-24 - Contextual Accessibility for Repeating Layouts
**Learning:** Icon-only buttons repeated within card layouts (like favorite or share buttons) can be confusing for screen reader users if they all have identical, generic labels (e.g., "Favorite"). Additionally, `title` attributes act as helpful tooltips for sighted users unsure of the icon's meaning. Using `:focus-visible` instead of `:focus` drastically improves keyboard navigation UX without creating visual noise for mouse users.
**Action:** When adding icon-only buttons to repeated components (like cards or lists), dynamically generate `aria-label` and `title` attributes using contextual data (like the item's title or name) to ensure uniqueness and clarity. Replace `:focus` with `:focus-visible` where possible and ensure the outline has high contrast.
