## 2024-05-15 - Context-Aware ARIA Labels in Repeating Card Layouts
**Learning:** Icon-only buttons (like a favorite heart) inside repeating card components create an accessibility trap if given a static `aria-label` (e.g., "Favorite"), resulting in screen readers announcing "Favorite, button" multiple times without context on *what* is being favorited. Furthermore, `title` attributes on these identical buttons fail to aid sighted users who rely on tooltips for context. Changing the CSS `:focus` to `:focus-visible` with a high-contrast outline (`outline: 2px solid var(--color-primary)`) also significantly reduces visual noise for mouse users while ensuring keyboard navigators can distinctly locate their focus within the repeating pattern.
**Action:** Always inject dynamic, context-aware values into `aria-label` and `title` attributes for repeating icon-only buttons (e.g., "Favorite Monti" extracted from an adjacent heading or link) and rely on `:focus-visible` with custom offset and color instead of a generic `:focus` background shift.
