## 2024-03-26 - Dynamic ARIA Label Extraction & Focus-Visible Patterns
**Learning:** In repeating card layouts with icon-only buttons (like favorite buttons), `aria-label` and `title` attributes must be dynamic and context-aware (e.g., extracting the adjacent item's name). Using static labels causes severe accessibility issues (duplicate labels) and confusing tooltips. Furthermore, relying on standard `:focus` states can create visual noise for mouse users, whereas `:focus-visible` with a high-contrast outline offers superior keyboard accessibility without impacting mouse interaction.
**Action:** Always extract context from adjacent structural elements (like headings or link texts) when programmatically injecting `aria-label` or `title` into icon-only buttons in lists/cards. Always substitute `:focus` with `:focus-visible` coupled with an explicit, high-contrast `outline` (e.g., `2px solid var(--color-primary); outline-offset: 2px;`) for interactive UI components to balance keyboard and mouse user needs.
